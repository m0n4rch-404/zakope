# Zakovat Ensiklopediya

GitHub Pages uchun tayyor mustaqil sayt.

## Fayllar
- `index.html` — sayt, JavaScript va faktlar bazasi bitta fayl ichida.
- `README.md` — ushbu yo‘riqnoma.
- `.nojekyll` — GitHub Pages fayllarni Jekyll orqali qayta ishlamasligi uchun.

## Joylash tartibi
1. Uchala faylni GitHub repozitoriyining bosh sahifasiga yuklang (`/` papkaga).
2. `Settings → Pages` ga kiring.
3. `Source: Deploy from a branch`, `Branch: main`, papka `/(root)` ni tanlab `Save` bosing.
4. `Actions` ichida `pages-build-deployment` jarayoni yashil belgi bilan tugashini kuting.

Alohida JSON fayli kerak emas: ma’lumotlar `index.html` ichiga joylangan.

Eslatma: faktlar PDF matnidan avtomatik yig‘ilgan; ayrim yozuvlar va tasniflarni qo‘lda tekshirish zarur bo‘lishi mumkin.
